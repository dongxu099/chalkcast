# A repeatable narration demo

ChalkCast turns a topic into a reviewable storyboard, narrated animation, subtitles and usage report. A local Studio and a CLI share one pipeline. A free demo runs without credentials. Users can supply an OpenAI-compatible planner and ElevenLabs narration.

Success means a first-time user can render a bundled example, edit the story before spending money, compare narration models, inspect measured latency and provider character-cost, and re-render without paying for unchanged audio.

The first release supports bounded chart, bars, flow and equation scenes. It does not claim arbitrary cinematic animation or mathematical verification. Educational facts require human review. The visual language uses original geometric animation inspired by mathematical explainers; no creator voice cloning or branding.
